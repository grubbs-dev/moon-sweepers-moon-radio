# Moon Radio for Moon Sweepers

Moon Radio adds shared internet radio to Moon Sweepers stations and eligible vehicles.

- `R` opens the radio in stations and seated eligible vehicles.
- Genre/search discovery and direct HTTPS MP3 streams.
- Independent radio state per station and vehicle.
- Positional multiplayer audio with a 200 m station range and 15 m vehicle range.
- Native-styled `RADIO R` shortcut that follows the vehicle HUD.

The ready-to-install package is in [`release/`](release/). Marketing assets are in [`media/`](media/).

See [`release/README.md`](release/README.md) for installation and requirements.
