# Moon Radio

Turn Moon Sweepers stations and eligible vehicles into shared internet radios. Press `R` to choose a station, search by genre, or paste a direct HTTPS MP3 stream. Each station and vehicle has its own radio, with positional audio for nearby multiplayer players.

## Quick install

Extract the archive into the Moon Sweepers game folder. The DLL should end up at:

`BepInEx/plugins/MoonRadio/MoonRadio.dll`

Requires Moon Sweepers 1.0.5, BepInEx 6.0.0-be.791 Unity IL2CPP win-x64, and the MoonSweepers BepInEx Patcher.
