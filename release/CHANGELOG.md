# Changelog

## 0.1.4

- Hide the `RADIO R` HUD hint while the game's pause menu is open, matching the native shortcut hints.
- Restore the hint when gameplay resumes.

## 0.1.3

- Restored the native-height HUD shortcut placement for the fallback `RADIO R` hint.
- Shifted the fallback hint right to align with the game's native shortcut column.
- Kept the fallback hint on the live HUD canvas and preserved the working `R` input path.

## 0.1.1

- Bugfix release: hide the RADIO shortcut while another station interaction screen owns the HUD prompt layer.

## 0.1.0

- Initial public release.
- Added station and vehicle radio controls.
- Added genre/search station discovery and direct HTTPS MP3 URLs.
- Added per-station and per-vehicle emitter state.
- Added positional multiplayer radio audio.
- Added native-styled `RADIO R` HUD hint with vehicle HUD re-homing.
